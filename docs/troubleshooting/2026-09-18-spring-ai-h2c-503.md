# Spring AI 채팅 요청의 503 오류

## 증상

`curl`로 임베딩을 요청하면 성공하지만, 백엔드의 `/api/ai/chat`은 503을 반환했다.
백엔드 로그에는 `422: body Field required`, 게이트웨이에는 `Unsupported upgrade request`가 기록됐다.

## 원인

JDK 21 HTTP 클라이언트의 기본 HTTP/2 업그레이드(h2c) 요청을 Uvicorn 0.40.0 게이트웨이가 정상 처리하지 못했다.
검색어 임베딩 요청이 본문 누락으로 422를 받았고, `PgVectorSearchAdapter`가 이를 503으로 변환했다.
채팅 답변 생성 전 단계에서 발생한 오류이며, HTTP/2로 LLM을 사용할 수 없다는 의미는 아니다.

## 해결

채팅·임베딩이 공유하는 [LlmConfig](../../ai/src/main/java/dev/iamrat/ai/support/infrastructure/llm/LlmConfig.java)의 HTTP 클라이언트를 HTTP/1.1로 고정했다.

```java
HttpClient.newBuilder()
    .version(HttpClient.Version.HTTP_1_1)
    .connectTimeout(connectTimeout)
    .build();
```

## 검증

동일한 요청에서 HTTP/2 우선 설정은 422, HTTP/1.1은 200을 반환하는 것을 확인했다.
채팅·임베딩 요청의 `Upgrade` 헤더가 사라지는 회귀 테스트와 백엔드 빌드가 통과했다.
운영 반영 후 실제 `/api/ai/chat` 정상 응답 확인은 별도로 필요하다.
