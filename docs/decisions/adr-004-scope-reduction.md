# ADR-004 가격·상품 축 제거

상태: **Accepted — 기능 삭제 결정 유지** (2026-08-18 실행 완료). 당시 제품 정의와 부활 조건은 [ADR-005](./adr-005-subscription-information-service.md)로 대체되었다.

이 문서는 당시 가격 비교·상품 수집·구매 판단 기능을 삭제한 이유를 보존하는 이력이다. 현재 제품 정의는 ADR-005가 소유한다.

## 배경

- 가격 축의 유일한 데이터 소스였던 Naver Shopping API가 종료되어 price check와 상품 수집은 프로덕션에서 동작할 수 없었다.
- 최저가 계산보다 지속 가능한 가격 데이터 확보와 소스 간 상품 동일성 판별이 선행되어야 했지만, 사용할 프로덕션 소스가 없었다.
- 소비자가 없는 messaging/outbox, 항상 비어 있는 상품 연결, 고아 AI 코드와 1:1 통과 계층도 유지 비용만 만들었다.

## 결정

- 가격 비교, 가격 추적, 상품 수집·catalog·matching, 구매 판단 투표를 삭제한다.
- 소비자가 없는 messaging/outbox와 상품 연결 등 실행되지 않는 코드도 삭제한다.
- 뉴스 수집·게시, RAG 채팅과 문서 적재는 유지한다.
- 복구용 동결 코드나 feature flag를 두지 않고 git history를 사용한다.

## 실행 결과와 후속 변경

- `post_reference_links.product_id`와 관련 파라미터를 제거하고 뉴스 중복·일일 한도 기준을 keyword와 발행일로 좁혔다.
- 당시에는 별도 drop migration을 추가했으나, 이후 폐기 가능한 데이터임을 확인하고 현재 schema를 `V0000` baseline으로 다시 정리했다. 2026-09-08 기준 migration 정본에는 `V0000`과 봇 계정/FK용 `V0001`만 있다.
- 구매 판단 중심이라는 당시 제품 문장과 가격 기능의 부활 조건은 ADR-005가 대체했다. 가격·특가·구매 판단은 현재 제품 범위가 아니다.

## 영향

- 삭제된 기능이 다시 필요하면 이 ADR의 문구를 부활 조건으로 사용하지 않고, 현재 제품 목표와 데이터 소스를 근거로 새 결정을 작성한다.
- 서비스 분리나 비동기 전달이 실제로 필요해질 때 event/outbox 설계를 새로 판단한다.
