# ADR-008 뉴스 자동 게시를 종료하고 사용자 자료 기반 학습 플랫폼으로 전환

상태: **Accepted** (2026-10-02). [ADR-005](./adr-005-subscription-information-service.md)의 제품 정의를 대체한다. [ADR-007](./adr-007-remove-naver-news-source.md)이 미뤄 둔 "후속 수집원"에 대한 결정이기도 하다. 다른 뉴스 수집원은 찾지 않는다.

## 배경

ADR-007 뒤에 다른 수집원으로 같은 파이프라인(수집 → 선별 → LLM 초안 → 게시 → 데일리)을 살릴 수 있는지 확인했다. 세 가지가 막았다.

1. **수집원 약관.** 2026-10-02에 다음을 원문으로 확인했다.
   - Google News RSS 피드: `<copyright>`에 "solely for the purpose of rendering Google News results within a personal feed reader for personal, non-commercial use. Any other use of the feed is expressly prohibited"라고 적혀 있다.
   - `news.google.com/robots.txt`: `/rss/`를 모든 봇에 열지 않고, GPTBot·ClaudeBot 같은 AI 봇은 사이트 전체를 차단한다.
   - 국내 언론사 RSS 15곳: 자동 수집·저장·AI 처리·외부 게재를 함께 허용한 곳이 한 곳도 없었다. 연합뉴스 피드는 "무단 전재-재배포, AI 학습 및 활용 금지"라고 적고, 뉴스1·한국경제·머니투데이는 목적과 무관하게 자동 수집과 AI 이용을 금지한다.
   - 허용 범위가 확인된 출처는 보도자료 배포처 뉴스와이어(웹사이트 노출 허용, 저장·AI 처리는 약관에 없음)와 정부 보도자료(공공누리 1유형) 두 가지뿐이었다.
2. **사실성 실측.** 같은 날 Google 수집원으로 로컬 E2E를 돌리고, 게시된 출시 글 4건을 원문 기사와 대조했다.
   - 피드 description이 "제목 (언론사)"뿐이어서 LLM(qwen3:8b)이 제목 한 줄로 본문을 썼다.
   - 3건에 원문과 다른 내용이 들어갔다. 장르·기능을 잘못 적었고, 원문에 있는 사양을 "언급 없음"이라고 고지했다.
   - RSS의 GMT 날짜 문자열을 그대로 받아 날짜가 하루씩 밀렸다.
   - ADR-007 배경 2(입력보다 긴 글은 원문에 없는 내용을 만든다)를 측정으로 확인한 셈이다. 본문을 입력으로 쓸 수 없는 한 LLM이 쓰는 기사의 사실성은 보장할 수 없다.
3. **아웃링크 대안의 한계.** "RSS 여러 개를 모아 제목과 링크만 노출하고, AI로 같은 사건을 묶어 검색하게 하는" 설계도 검토했다.
   - 링크와 제목만 쓰는 것은 판례상 방어할 수 있다(대법원 2012도13748, 2017도19025 전원합의체, 서울중앙지법 2022가합558462).
   - 그러나 막힌 지점은 저작권이 아니라 피드 약관이어서, 쓸 수 있는 출처를 정하지 못했다.

학습용 외부 자료도 같은 기준으로 확인했다(2026-10-02).

| 자료 | 판단 |
| --- | --- |
| Spring·Oracle 공식 문서 | 재사용할 수 없다 |
| PostgreSQL·Python·Kubernetes 문서, Wikidata, MIT 라이선스 레포 | 출처를 표기하면 쓸 수 있다 |
| Stack Exchange | 생성형 AI용 수집을 금지한다 |
| 백준 | 서비스가 종료됐다 |

외부 콘텐츠를 적재하는 제품은 출처가 바뀔 때마다 이 판단을 다시 해야 한다.

## 검토한 대안

| 대안 | 판단 |
| --- | --- |
| Google News RSS로 자동 게시 유지 | 피드 고지와 robots.txt가 개인 피드 리더 외 사용과 봇 수집을 금지한다. 사실성 문제도 그대로다. |
| 언론사 RSS 집계 + 아웃링크 + AI 클러스터링 검색 | 링크·제목은 판례상 방어할 수 있지만, 확인한 언론사 15곳 중 이 사용을 허용한 곳이 없다. |
| 뉴스와이어 보도자료만 수집 | 웹사이트 노출은 허용하지만 저장·AI 처리는 약관에 없어 서면 확인이 필요하다. 제품 범위도 보도자료로 좁아진다. |
| 정부 보도자료(공공누리 1유형)만 수집 | 저장·AI·상업 이용이 모두 가능하지만 제품 출시 소식이 거의 없다. |
| 팀 기술면접 스터디 공간 | 사용자 자료 기반이라 라이선스 문제가 없다. 학습 효과를 확인한 뒤 확장 후보로 둔다. |
| 코드 레포 분석(codeintel) | 확장 후보로 둔다. |
| LLM이 학습 문서를 생성 | 뉴스와 같은 사실성 문제가 생긴다. 기각한다. |

## 결정

- **제품:** 사용자가 올린 자료(문서·노트)로 네 가지 학습을 하게 하고, 간격 반복으로 다시 보게 하는 학습 플랫폼으로 전환한다. 웹을 먼저 만들고 앱은 그 뒤에 한다.
  - 복습 문제에 답하기(인출)
  - 빈 페이지에 처음부터 정리하기(자유 회상)
  - AI 학생에게 가르치기
  - 문제를 만들어 풀기
- **원칙**
  - LLM은 묻거나 제안만 하고 채점하지 않는다.
  - 모든 문제는 근거 문장이 자료에 그대로 있어야 복습 목록에 들어간다. 이 검증은 결정적으로 한다.
  - 매일 반복하는 루프(오늘 할 것, 채점, 빈 페이지 대조, 간격 계산)에는 LLM 호출을 넣지 않는다. 꼬리질문은 사용자가 버튼을 누를 때만 한 번 호출한다.
  - LLM이 쓴 학습 문서를 자료로 저장하지 않는다.
  - 라이선스를 확인하지 않은 외부 콘텐츠를 적재하지 않는다.
- **삭제 목록:** 학습 루프가 완성된 뒤 한 번에 지우고, 그때 Flyway `V0000`을 동결한다.
  - 뉴스 수집·선별·스케줄 게시·데일리 종합(`ingest/news`)
  - 외부 뉴스 adapter(`source` 모듈)
  - 뉴스·데일리 초안 생성기와 발행 전용 LLM 경로(`ai/draft`)
  - 뉴스 코퍼스 RAG(`ingest/document`, `vector_store`)
  - 첨부파일과 S3
  - 게시판(board)과 네이버 OAuth 로그인은 유지한다.
- **게이트 기준(사전 등록):** 학습 루프를 완성한 날부터 도그푸딩한다. 첫 7일 간격 복습이 돌아오는 11일째 이후에 아래 세 기준으로 판정한다.
  - 11일 중 8일 이상 사용한다.
  - 7일 간격 복습에서 '알았음' 비율이 70% 이상이다.
  - LLM이 만든 문제의 근거 검증 통과율이 80% 이상이다. 분모는 자료를 올릴 때와 꼬리질문에서 LLM이 낸 초안 전부다(2026-10-02, 도그푸딩 시작 전에 측정 범위를 정함).
  - 하나라도 못 미치면 확장하지 않고 원인을 분석해 방향을 다시 본다. 기준과 데이터는 판정 뒤에 고치지 않는다. 고쳤다면 그 사실을 이 문서에 기록한다.

## 결과

- 입력이 사용자 본인 자료라 외부 콘텐츠 라이선스 위험이 없다.
- 사실성은 근거 문장 검증으로 다룬다. 뉴스 E2E에서 측정한 실패, 즉 입력에 없는 사실을 만드는 문제를 구조적으로 막는 방향이다.
- 기술 과제가 바뀐다.
  - 근거 검증
  - 재시작해도 이어지는 비동기 문제 생성
  - 동시 제출 시 중복 채점 방지
  - 간격 반복 일정 계산
- Google News RSS 수집원은 뉴스를 지우기 전까지 실험용으로만 남긴다. 기본값은 비활성이고 배포 환경에서 켜지 않는다.
